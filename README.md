## 📖 Overview

The **AviTech Solutions Website** is a fully responsive static web platform designed to represent the brand’s online presence and simplify client interaction.

It allows users to:
- Explore IT services
- View pricing in UGX (Uganda market-focused)
- Submit appointment requests
- Contact the business directly via multiple channels

---

## ✨ Key Features

### 🖥️ Responsive Design
- Fully optimized for mobile, tablet, and desktop devices
- Modern UI with smooth navigation

### 🛠️ Service Presentation
- Clearly structured IT service categories
- Direct booking links per service

### 💰 Uganda Pricing System
- Localized pricing displayed in UGX
- Transparent service cost structure

### 📅 Appointment Booking System
- Appointment request form with:
  - Service selection
  - Budget input
  - Date & time scheduling
  - Urgency level
  - Support type selection

### 📊 Google Sheets Integration
- Automatically stores appointment data in Google Sheets
- Real-time tracking of client requests

### 📱 Contact Options
- WhatsApp integration
- Email contact
- Direct phone support links
